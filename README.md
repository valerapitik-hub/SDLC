# SDLC — Расчёт суточной нормы протеина

**Автор:** Питковский Валерий, гр. 439401
**Дисциплина:** Жизненный цикл разработки программного обеспечения


Проект представляет собой десктопное приложение с графическим интерфейсом
на языке C++ с использованием библиотеки Qt. Приложение рассчитывает
суточную норму потребления протеина по введённому весу пользователя
(в килограммах или фунтах).
